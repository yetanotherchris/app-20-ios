# Data Model

## Provider settings snapshot

Retain `apiKey` and `s3`; add optional `endpoint` (normalized absolute HTTPS base URL) and `modelPreferences` (map of normalized endpoint to unique exact nonempty identifiers). Missing map entries differ from `[]`. OpenRouter's missing entry resolves to `['openrouter/auto']`; other missing entries resolve to `[]`. Protected storage retains all endpoint lists when the active endpoint changes. Public imports use `enabledModels`, not the internal map.

## Catalog model and cache

`CatalogModel`: `id: string`, `name: string`. Exact identifiers deduplicate; names and identifiers are searched case-insensitively. Complete cached lists are keyed by endpoint and hold no key. Saved enabled models absent from discovery remain visible as unlisted. Loading or failure does not replace the last successful cache.

## Conversation selection

Conversation keeps `model: string`; optional `selectionProvenance` carries normalized `endpoint`. Only this credential-free property is generated by selection. JSON and S3 preserve it backwards compatibly. A restored selection is valid only if endpoint and enabled identifier match; missing provenance follows legacy rules. New conversation default applies only to new conversations.

## State transitions

Settings: hydrated → edited draft → saving → committed, or failed retained draft → retry. Endpoint, API key and imported list commit together. Catalog: loading → complete/empty/error; query filters cached rows without changing enabled choices. Conversation: no selection → explicit selection → invalidated when endpoint or enabled list becomes incompatible. In-flight request captures settings and model once.
