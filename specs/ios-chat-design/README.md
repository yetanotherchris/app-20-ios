# iOS chat design package

Start with **visual-spec.md**, then use **state-index.md** to inspect individual states. **preview.html** is an offline, one-screen-at-a-time viewer; open it after extracting the ZIP. There is no multi-screen collage.

The package incorporates Openrouter Auto, optional S3 (local saves always; S3 mirroring when configured), automatic settings saving, secret eye controls, edit-and-resend under user prompts, and scroll-to-latest.

PNG artwork was generated with the built-in image tool and visually reviewed. It is design guidance, not a running iOS simulator capture. Use the specified point measurements, SVG glyphs, native system presentations and runtime insets when implementing. Existing transcript styles remain authoritative except for the added prompt action.

Contents: 35 annotated PNGs, 16 SVG icons, TypeScript tokens/types, Markdown specification and state index, example JSON/TXT configuration, and this preview. All example credentials are fake. No brand illustrations are required.
